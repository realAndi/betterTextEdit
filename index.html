    Not a website in a window

    Native, in the way that shows

    Written in Swift against SwiftUI and AppKit. It starts instantly, weighs about three megabytes, and uses the system's own furniture rather than redrawing approximations of it.

    Text engine

    AppKit's own

    The editor is NSTextView — so spelling, substitutions, Services, the Emoji picker and every key binding you already have muscle memory for are simply there.

    Liquid Glass

    Three window surfaces

    Solid, Glass or Clear. Glass is NSGlassEffectView tinted by the theme, not a blurred screenshot faking it.

    System panels

    The real Font and Colour windows

    ⇧⌘T and ⇧⌘C open the panels every Mac app shares, with your favourites already in them.

    Binary

    Universal, signed, notarised

    One build for Apple silicon and Intel, signed with a Developer ID and notarised by Apple, so it opens on a double-click.

    Free · open source · updates itself

    Give it your messiest folder

    It checks for new versions once a day and installs them when you say so. Nothing to subscribe to, no account, no telemetry.
